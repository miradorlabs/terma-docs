<Info>
  **Coming soon.** Antigravity appears as **Coming Soon** in the `terma setup` agent picker, and you can't connect it yet. This page describes what Terma will capture once it is available. Today, `terma setup` connects [Claude Code](/integrations/claude-code) and [Codex](/integrations/codex).
</Info>

Google's Antigravity CLI (`agy`) replaced Gemini CLI for many users in June 2026. It has no configurable OpenTelemetry export, so everything Terma learns about an `agy` session will arrive through its lifecycle hooks. Support will be **partial**: commits are attributed and every tool step is recorded, but `agy` reports no token counts or cost.

## What's captured

| Signal | Available |
|---|---|
| Commit attribution | Yes |
| Sessions and turns | Yes |
| Model per call | Yes |
| Every tool step, with completed or error status | Yes |
| Files edited, for commit attribution | Yes |
| Token counts, cost, plan, and quota | No — `agy` does not report them |
| Tool durations | No |
| Prompt, response, and command text | No — hooks never read it |

Treat Antigravity data in Terma as evidence of activity, not usage or spend. `agy` has no session-end hook, so a session is closed after a period of inactivity.
