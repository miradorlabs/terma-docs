The Terma CLI (`terma`) is a single static binary with no runtime dependency. Install it, then run [`terma setup`](/cli/setup).

## Install the CLI

<CodeGroup>

```bash Install script
curl -fsSL https://terma.ai/install.sh | bash
```

```bash npm
npm install -g @miradorlabs/terma
```

```bash Homebrew
brew tap miradorlabs/tap
brew trust miradorlabs/tap     # once; Homebrew will not load an untrusted tap
brew install terma
```

</CodeGroup>

Every method installs the same release and verifies it against the release's `checksums.txt`. We recommend the install script: it is the only installation that can [update itself automatically](/cli/update#automatic-updates).

<Warning>
  **Homebrew does not update terma automatically**, and neither does npm. When terma is owned by a package manager, it only tells you when a new release is out. Run `terma update` (or `brew upgrade terma`) to install it. See [Homebrew and npm installs](/cli/update#homebrew-and-npm-installs).
</Warning>

### Install script options

The install script is POSIX `sh`, so `| sh` works too. It picks the archive for your platform, verifies the checksum, and places the binary in `~/.local/bin`. It never asks for sudo. If `~/.local/bin` is not on your `PATH` yet, the script prints the line that adds it.

| Variable | Effect |
|---|---|
| `TERMA_INSTALL_DIR` | Install the binary to this directory instead |
| `TERMA_VERSION` | Install a specific release, for example `TERMA_VERSION=v1.2.3` |

### Direct download or source

Native binaries for macOS, Linux, and Windows are published on [GitHub Releases](https://github.com/miradorlabs/terma-cli/releases) with checksums and signed provenance. To build from source, clone the repository and run `make install`.

<Note>
  A source build is never updated automatically. Run `terma update --force` to switch it to the latest published release.
</Note>

## Verify the installation

```bash
terma --version
```

## System requirements

- **Operating system:** macOS or Linux (x86_64 or arm64). Windows binaries are available from GitHub Releases.
- **Runtime:** none. The binary is self-contained.
- **Git:** needed for repository matching and commit stamping.

## Remove the CLI

Run [`terma teardown`](/cli/teardown) first to restore your agents' settings and stop the relay. Then remove the binary with the method you installed it with, for example `npm uninstall -g @miradorlabs/terma` or `brew uninstall terma`.
