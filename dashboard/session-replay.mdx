The **Sessions** page lists every agent session in the team with what it used and cost. Open a session to replay it: every prompt, response, and tool call in order, alongside its token timeline, files, and git activity.

## The sessions list

At the top, four cards summarize the period: **Active now** (sessions reporting in the last 10 minutes), **Model calls**, **Tokens burned**, and **Spend** (or **Net spend**, or **Output tokens**, depending on the usage view). Totals count whole sessions.

### Finding sessions

- **Search** across sessions, users, models, and repositories.
- **Harness chips** — **All harnesses**, or one per source — appear when more than one source reported.
- **Filters** for model, provider, effort, client, or person appear as removable chips when you arrive from a link on another page, such as a model or person.
- **Sort** by cost (or tokens) or by time.

### Columns

| Column | Description |
|---|---|
| **Session** | The session's title and source |
| **Model** | The model it used |
| **User** | The person or API key it is attributed to |
| **Client** | The agent and its version |
| **Active** | When it was last active |
| **Turns** | Prompts from the person |
| **Tokens** | Total tokens (hidden in the Tokens view, where cost shows tokens instead) |
| **Cost** | Spend in the current usage view |

Rows blink when new activity arrives. A session that spawned subagents has an **N subagents** toggle that expands its tree; the parent's totals include its subagents.

Expand a row to see its recap, timing (duration, started, last active), git activity (commits, pushes, branches, repositories), work (tool calls, model calls, subagent runs, cached tokens, files touched, effort, who billed it, client version), and usage over time by model.

## Session detail

Open a session to see its full record. **Copy session ID** copies the id used in commit trailers.

### Summary

- **Session cost** — a breakdown of the session's cost by how it was funded: **Subscription**, **Prepaid credits**, **Metered**, or **Funding unknown**. An **Estimated** badge means Terma priced tokens the source did not price itself. In the Tokens view this becomes **Session tokens**.
- The source and model, activity span, turns, tokens (with the share read from cache), and counts of files, commits, pull requests, models, and subagents.
- For sessions with subagents, an **agents table** lists each agent's model, tokens, and own cost.

### Token timeline

The token timeline charts the session's token usage over time by type — cache read, input, cache write, output — with markers where subagents were spawned and where git actions happened.

- **Click** a point to peek at what happened there, and step to the previous or next event.
- **Drag** to select a range; the replay below narrows to it.

When a session has subagents, an **Agent execution** chart shows when each agent ran, as a timeline or by token usage. Drag to zoom.

### Session replay

The replay shows the session's events in order. Filter it to **All**, **Conversation**, **Tools**, or **Errors**, search messages, tools, and files, and expand or collapse tool calls. Navigation buttons jump between your prompts, and **Expand reader** widens the transcript.

Compactions — where the agent summarized earlier context to make room — appear as a short note in the transcript. Content appears only if the agent was configured to export it; see [Privacy and security](/concepts/privacy).

### Sidebar

| Panel | What it shows |
|---|---|
| **Model usage** | Calls and tokens per model, and the providers that served them |
| **Files changed** | Files created, edited, removed, or only read; select one to filter the replay to it |
| **Git activity** | Branches, commits, pushes, and pull requests the session produced, with an **AI co-authored** flag |
| **Tokens by cache tier** | How the session's tokens split across cache tiers |
| **Observed performance** | Average model call time, time to first token, tool result time, and compactions |
