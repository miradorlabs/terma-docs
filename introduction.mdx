Terma gives engineering teams one place to see what their AI coding agents are actually doing. It captures sessions from agents like Claude Code and Codex, prices every model call, tells subscription-covered spend from metered spend, and stamps each commit with the sessions that produced it — so you can trace agent spend all the way to shipped code.

## How it works

<Steps>
  <Step title="Install Terma in a repository">
    Run `terma install` in a repository. It binds the repository to a Terma project, points your coding agents at that project, and writes commit and agent hooks into files you commit — so one merged pull request onboards everyone who works there.
  </Step>
  <Step title="Work as usual">
    Your agents export their usage to Terma as they run. Terma's hooks record which files each session edits and stamp your commits with `Agent-Session-Id` and `Agent-Tool` trailers. Nothing waits on the network.
  </Step>
  <Step title="See where the effort goes">
    The dashboard shows spend and a live burn rate, every session with a full replay, usage by person and model, the pull requests agent sessions contributed to, and a burn map of agent work that has — and has not — reached Git.
  </Step>
</Steps>

## Supported tools

| Tool | Support |
|---|---|
| **Claude Code** | Full: telemetry, commit attribution, and plan usage |
| **Codex CLI** and **Codex Desktop** | Full: telemetry, commit attribution, and plan usage |
| **OpenCode** | Telemetry and attribution through a plugin; advanced setup |
| **Cursor** | Commit attribution and session observations; no cost data |
| **Antigravity CLI** | Commit attribution and session observations; no cost data |
| **OpenRouter** | Every routed call, through OpenRouter Broadcast |
| **Any OpenTelemetry source** | Send to your project with a server key |

Cursor, OpenCode, and Antigravity are marked **Coming Soon** in the CLI's onboarding; each integration page explains what you can set up today.
