Terma gives engineering teams one place to see what their AI coding agents are actually doing. It captures sessions from agents like Claude Code and Codex, prices every model call, tells subscription-covered spend from metered spend, and stamps each commit with the sessions that produced it — so you can trace agent spend all the way to shipped code.

## How it works

<Steps>
  <Step title="Set up your machine once">
    Run `terma setup`. It signs you in, chooses your team, points your coding agents at a relay on your machine, and writes their machine-wide hooks. Nothing is written into your repositories: your team's collection policy decides which repositories are collected.
  </Step>
  <Step title="Work as usual">
    Your agents export their usage to Terma as they run. Terma's hooks record which files each session edits and, when your team's policy turns on commit stamping, stamp your commits with `Agent-Session-Id` and `Agent-Tool` trailers. Nothing waits on the network.
  </Step>
  <Step title="See where the effort goes">
    The dashboard shows spend and a live burn rate, every session with a full replay, usage by person and model, the pull requests agent sessions contributed to, and a burn map of agent work that has — and has not — reached Git.
  </Step>
</Steps>

## Supported tools

| Tool | Support |
|---|---|
| **Claude Code** and **Claude Desktop** | Full: telemetry, commit attribution, and plan usage |
| **Codex** (TUI and Desktop) | Full: telemetry, commit attribution, and plan usage |
| **OpenCode** | Coming soon |
| **Cursor** | Coming soon |
| **Antigravity CLI** | Coming soon |
| **OpenRouter** | Every routed call, through OpenRouter Broadcast |
| **Any OpenTelemetry source** | Send to your team with a team API key |

Cursor, OpenCode, and Antigravity are marked **Coming Soon** in `terma setup`; each integration page describes what Terma will capture.
